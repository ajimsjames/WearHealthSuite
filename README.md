# WearHealthSuite

WearHealthSuite is a comprehensive fitness, sensor telemetry, and real-time health scanning application for Wear OS.

## Features
- Real-time sensor telemetry including heart rate and SpO2 tracker\n- Wrist detection sensor integration for wear verification\n- Custom ECG pulse wave simulation visualization\n- AMOLED pitch black UI for battery conservation on OLED screens

## Installation
Install directly via the [WearAppStore](https://github.com/ajimsjames/WearAppUpdater) client on your watch.
